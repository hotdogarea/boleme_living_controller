# 闲置保护弹窗恢复

## 范围

- 基线：main `77db3a7e9367b33ac42da63ba5909f2019ec1a07`。
- 针对用户提供的“检测到您长时间未操作／为保障您的账号安全，系统已自动唤起保护机制”弹窗，按钮为“恢复”。
- 只在受管的抖店、百应、罗盘域名识别完整文案和唯一恢复按钮，兼容按钮文字空格及嵌套 dialog 容器。
- 不自动确认其他弹窗、不处理验证码或重新登录，不使用 force click，也不注入防挂机鼠标／键盘事件。

## 行为

- 原有约两秒一轮的页面维护检查已打开后台页面；发送文字、弹商品讲解前也检查。
- 点击恢复后等待原弹窗隐藏；失败时至少间隔十秒再试，同一持续弹窗最多三次，之后提示手动处理。
- 页面维护或“新评论”按钮点击异常只做限频日志，不再让异常直接退出采集线程。
- 发布前增加无副作用的 trial 检查。若此时出现已识别的保护弹窗，恢复后只重试检查，并核对评论框仍是原文案。
- 真正点击发布后的任何超时不自动重新发布，避免发送成功但确认超时时重复发言；其他遮挡仍然阻止当前操作。
- 真正发起发布前登记短期自回声抑制，避免响应比点击返回更早、或结果不明的超时导致自己的回复再次进入弹幕处理。
- 不重启浏览器、不清空登录资料，不改账号、采集会话、知识库或语音逻辑。本轮只更新源码，显示版本仍为 0.1.0，未打包。

## 验证

- 助手完整独立回归 49 项、主程序浏览器／桥接／客户端相关回归 22 项通过，共 71 项。
- Edge headless 使用临时上下文、拦截请求的本地模拟页面，未登录账号、未向真实直播间发测试文字。
- 验证正常恢复后仅发布一次、定时恢复不发言、捕获监听继续收到响应、未知弹窗和其他域名不点击、试点击阶段突现弹窗、恢复后草稿变化、发布后超时不重发、维护异常隔离及三次限额。
- 真实平台长时间挂机场景仍待登录联调；页面文案或结构改变时会拒绝自动处理并提示人工操作。
