# 弹幕类型在采集助手中统一选择

- 助手基线：`a5a38026d855ad1da00d75f3c2670fcae7e29270`。
- 语音引擎对应基线：`6be860b0994d34824be1396b4e348cd47c39d177`。
- 在直播互动页实时弹幕标题旁，点击“采集类型”选择评论、进房、点赞、关注。
- 抖音小店和巨量百应共享类型设置，默认保留全部已支持类型；其他平台仅显示当前实际支持的类型。
- 选择结果立即生效并自动保存到本机设置，重启恢复；全不选时不显示或推送新消息。
- 同一份选择同时控制助手显示和发送给语音引擎的事件，未选类型不进入显示队列或本机广播。
- 类型变化会清理待显示队列并重新筛选已有列表，和“只看未发送”组合生效。
- 保存失败时恢复原选择并记录错误，不声称保存成功。
- 语音引擎右侧移除新增的抖音类型行，不再读取遗留 `douyin_reply_types`；旧版插件仍自行控制类型。
- 本轮仅源码调整，不重新打包助手或语音主程序。

## 验证

新增 7 项类型选择测试，覆盖能力范围、显示与广播过滤、自动保存与重启、全不选、保存失败、排队消息及已有历史、平台切换。

助手仓库全部 21 项测试通过；语音引擎另验证了 18 项采集整合、5 项助手界面、5 项通信客户端、1 项本机通信和 27 项弹幕互动回归。两侧界面均已离屏渲染检查，尚未进行真实账号的长时间联调。
