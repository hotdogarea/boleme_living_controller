# 播了么直播中控助手

一款免费的开源直播中控工具，帮助商家在直播时查看弹幕、发送文字、安排快捷语和商品讲解。可以独立使用，也可以与播了么语音引擎搭配，把大模型生成的回复以文字形式发到直播间公屏。

## 主要功能

- **直播互动**：查看中控台弹幕，手动发送文字或回复评论。文字发送到公屏，并非定向艾特观众。
- **快捷语**：预设商品卖点、活动信息等话术，按设置的间隔自动发送。
- **商品讲解**：按商品序号、顺序和次数自动点击中控台的讲解按钮，单品也可以只设置一条。
- **多账号**：为不同平台和账号分别保存登录状态，切换账号时复用各自的浏览器资料。

目前提供抖音小店、巨量百应、抖音团购、小红书方舟与蒲公英、微信视频号、快手小店、淘宝直播等中控入口。不同平台开放的弹幕和操作能力并不完全相同；抖音团购目前不支持弹幕采集。平台页面更新后，相关功能可能需要适配。

## 运行源码

在 Windows 上安装 Python 3.10，在项目目录执行：

```powershell
.\setup.ps1
.\.venv\Scripts\python.exe -m boleme_live_control
```

启动后选择平台和账号，连接中控台，在打开的浏览器中完成登录。需要自动发送快捷语或商品讲解时，再开启对应功能。

登录资料和设置只保存在当前电脑的 `%LOCALAPPDATA%\Boleme\LiveControl`，不会随源码上传。项目采用 [MIT 许可证](LICENSE)；参考项目的许可信息见 [THIRD_PARTY_LICENSE.txt](THIRD_PARTY_LICENSE.txt)。

## 播了么生态

[播了么直播辅助系统](https://ct4586wcq7.feishu.cn/docx/KOz8dDi8xok25IxHN3PcKrVcnHh?from=from_copylink)面向直播场景，包含三部分：

- **播了么 AI 智播语音直播引擎**：讲解话术、学习产品知识，并用语音回应直播间互动。
- **播了么数字人对口型引擎**：用音频驱动数字人口型，可用于视频制作和直播。
- **播了么 iPhone 直推插件**：将直播画面推送到手机，再由手机开播。

这些工具可以按直播需要独立使用或搭配使用；本仓库的中控助手负责中控台操作。
